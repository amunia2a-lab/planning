# Garage Widget - Lookup modèle par plaque

Route API interne :
GET /api/vehicle?plate=AB-124-GD

Elle appelle l'API de plaque et tente d'extraire marque + modèle.
Il faudra peut-être ajuster les noms de champs après le premier test réel.

Format de titre RDV recommandé :
AB-124-GD | Colin | 0612345678 | Embrayage
